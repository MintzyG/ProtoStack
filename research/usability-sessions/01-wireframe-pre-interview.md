# Usability Session 01 (Wireframe): Pre-Use Interview Log

Participant: Client (Founder / Lead Stakeholder)
Phase: Low-Fidelity Wireframe Usability Test
Date: 2026-11-26

## Pre-Use Interview Responses

1. **Expected first screen before/after plug-in:**
   - If opened before plugging in: expects a clean "Please connect your Protogen" screen with a **Simulate** button (for browsing without hardware or exporting a config file).
   - Once connected: expects a live visor preview with quick face/color controls right next to it.
2. **Prior configurator experience:**
   - Wootility (Wooting) and Logitech G HUB.
3. **Top frustrations in hardware config apps:**
   - Text clutter and too many settings dumped on one screen.
   - Hunting through deep menus for basic actions.
   - Not knowing if a change is live or saved permanently.
   - Broken or confusing USB connection steps.
4. **Primary safety confidence mechanism:**
   - Edits preview in RAM only until pressing Save.

## Key Pre-Test Design Adjustment Made
- Added a clean "Connect your Protogen" + "Simulate" entry screen before the main workbench, and stripped all instructional/guiding text so the wireframe tests pure visual affordance and IA.
